# ΚΗΜΔΗΣ — Υπερ-Εργαλείο Αναζήτησης

Βρίσκει **ολόκληρη την αλυσίδα** μιας δημόσιας σύμβασης στο Κ.Η.Μ.ΔΗ.Σ. ξεκινώντας
από **οποιονδήποτε** κρίκο της — ΑΔΑΜ, ΑΔΑ Διαύγειας ή Α/Α ΕΣΗΔΗΣ — και την
παρουσιάζει με οικονομική ανάλυση και έτοιμες εξαγωγές.

```
Αίτημα → Διακήρυξη → Ανάθεση → Σύμβαση → Πληρωμή
```

Τρέχει με δύο τρόπους, από **τον ίδιο κώδικα**:

| | |
|---|---|
| 🧩 **Επέκταση Chrome** | `extension/` — καλεί το ΚΗΜΔΗΣ απευθείας, χωρίς proxy |
| 🌐 **Online εφαρμογή (PWA)** | `index.html` — για GitHub Pages· χρειάζεται τον Cloudflare Worker |

Ανάπτυξη: **developer V. Diakolios** — Δήμος Ρόδου, Διεύθυνση Τεχνικών Έργων και Υποδομών

## Τι κάνει

**Σάρωση αλυσίδας σε δύο κατευθύνσεις.** Δώσε έναν οποιονδήποτε ΑΔΑΜ — ακόμη και
από τη μέση της αλυσίδας — και βρίσκει και τα προηγούμενα και τα επόμενα στάδια.
Η σάρωση συνδυάζει τέσσερις πηγές: το πεδίο «προηγούμενος ΑΔΑΜ», αναζήτηση
απογόνων ανά στάδιο, τον κοινό Α/Α ΕΣΗΔΗΣ, και τους ΑΔΑΜ που εμφανίζονται μέσα
στα ίδια τα δεδομένα.

**Οικονομική εικόνα.** Σύνολα ανά στάδιο, ποσοστό απορρόφησης (πληρωμές έναντι
σύμβασης), έκπτωση έναντι του αρχικού αιτήματος, υπόλοιπο σύμβασης, και
προειδοποιήσεις όταν τα νούμερα δεν βγαίνουν (π.χ. πληρωμές πάνω από το
συμβατικό ποσό).

**Σωστά στοιχεία αναδόχου.** Τα ΑΦΜ ελέγχονται με τον επίσημο αλγόριθμο ψηφίου
ελέγχου και συλλέγονται μόνο από πεδία που όντως είναι ΑΦΜ — όχι με αναζήτηση
9ψήφιων αριθμών σε όλο το JSON, που έπιανε ημερομηνίες και ποσά.

**Τρεις τρόποι αναζήτησης.**
- *Αλυσίδα* — ένας κωδικός, όλη η ιστορία της σύμβασης
- *Μαζική* — επικόλλησε δεκάδες ΑΔΑΜ (π.χ. από Excel) και πάρε τους όλους σε πίνακα
- *Σύνθετη* — φίλτρα ανά ΑΦΜ φορέα, CPV, ημερομηνία, λέξη-κλειδί

**Εξαγωγές.** Excel (.xlsx με αυτόματα φίλτρα και μορφοποίηση νομίσματος), CSV
έτοιμο για ελληνικό Excel, καθαρό JSON, εκτυπώσιμη αναφορά, και πλήρες ZIP με
τα PDF όλων των πράξεων μαζί με τα μεταδεδομένα.

**Και ακόμη:** σκούρο θέμα, λειτουργία σε κινητό, ιστορικό αναζητήσεων,
ενσωματωμένα διαγνωστικά, ακύρωση αναζήτησης εν εξελίξει, αντιγραφή ΑΔΑΜ/JSON
με ένα κλικ, μενού δεξιού κλικ σε επιλεγμένο κείμενο.

## Εγκατάσταση — Επέκταση Chrome

1. Κατέβασε ή κλωνοποίησε το αποθετήριο.
2. Άνοιξε `chrome://extensions`.
3. Ενεργοποίησε τη **Λειτουργία προγραμματιστή** (πάνω δεξιά).
4. **Φόρτωση χωρίς συμπίεση** → επίλεξε τον φάκελο `extension/`.

Έτοιμο — δεν χρειάζεται τίποτε άλλο. Η επέκταση έχει `host_permissions` για το
ΚΗΜΔΗΣ, οπότε καλεί το API απευθείας.

Πατώντας το εικονίδιο ανοίγει ένα μικρό παράθυρο με δύο επιλογές:
- **🔗 Άνοιγμα εργαλείου** — ανοίγει το εργαλείο σε δική του καρτέλα *(συνιστάται)*
- **📄 Στη σελίδα** — το εμφανίζει ως επικάλυψη πάνω στη σελίδα του ΚΗΜΔΗΣ

Συντόμευση πληκτρολογίου: `Alt+K`.

> **Γιατί δική του καρτέλα;** Η v7 έκανε ένεση του εργαλείου μέσα στη σελίδα του
> ΚΗΜΔΗΣ. Αυτό σημαίνει ότι κάθε αλλαγή στον ιστότοπο μπορεί να το χαλάσει, και
> τα στυλ των δύο σελίδων μπερδεύονται. Η σελίδα της επέκτασης δεν έχει καμία
> από αυτές τις εξαρτήσεις. Η επικάλυψη παραμένει διαθέσιμη για όταν τη θες.

### Έτοιμο πακέτο
```bash
./build.sh --zip     # → dist/kimdis-extension-v8.0.0.zip
```

## Εγκατάσταση — Online εφαρμογή

### 1. Ο Worker (μία φορά)

Η online έκδοση **δεν μπορεί** να καλέσει το ΚΗΜΔΗΣ απευθείας: ο browser το
μπλοκάρει, επειδή ο server του ΚΗΜΔΗΣ δεν στέλνει κεφαλίδες CORS. Χρειάζεται
έναν ενδιάμεσο.

```bash
npm install -g wrangler
wrangler login
cd worker && wrangler deploy
```

Πλήρεις οδηγίες, και εναλλακτικός τρόπος χωρίς τερματικό: **[`worker/README.md`](worker/README.md)**

### 2. Δημοσίευση σελίδας

Settings → Pages → Source: **Deploy from a branch** → `main` / `/ (root)`.

Η σελίδα θα είναι στο `https://vasilis1730-web.github.io/kimdis/`.

### 3. Σύνδεση

Άνοιξε τη σελίδα → **⚙️ Ρυθμίσεις** → επικόλλησε το URL του Worker →
**Αποθήκευση** → **🩺 Διαγνωστικά** για επιβεβαίωση.

Το URL μένει αποθηκευμένο στον browser σου. Μπορείς επίσης να το μοιραστείς
έτοιμο: `...?proxy=https://kimdis-proxy.xxx.workers.dev`

### Τοπική δοκιμή
```bash
python3 -m http.server 8000
```
Άνοιξε `http://localhost:8000`. *(Με διπλό κλικ στο αρχείο δεν δουλεύει — ο
browser μπλοκάρει τη φόρτωση των αρχείων.)*

## Δομή

```
src/                  ← Ο ΚΩΔΙΚΑΣ ΖΕΙ ΕΔΩ. Άλλαξε μόνο αυτά.
  khmdis-core.js        API, σάρωση αλυσίδας, ανάλυση, εξαγωγές
  khmdis-ui.js          Ολόκληρη η διεπαφή
  khmdis-ui.css         Στυλ (φωτεινό/σκούρο/εκτύπωση/κινητό)
  vendor/jszip.min.js

assets/               ← αντίγραφα του src/ (τα χρησιμοποιεί η online σελίδα)
extension/assets/     ← αντίγραφα του src/ (τα χρησιμοποιεί η επέκταση)

index.html            online εφαρμογή      manifest.webmanifest   PWA
sw.js                 service worker       build.sh               συγχρονισμός + zip
extension/            επέκταση Chrome      worker/                Cloudflare Worker
test/                 έλεγχοι
```

**Ο κοινός κώδικας γράφεται μία φορά** στο `src/` και αντιγράφεται στους δύο
καταναλωτές του (ένας φάκελος επέκτασης δεν μπορεί να διαβάσει αρχεία έξω από
αυτόν, και το GitHub Pages σερβίρει στατικά — γι' αυτό αντίγραφα και όχι
σύνδεσμοι).

```bash
./build.sh            # μετά από κάθε αλλαγή στο src/
./build.sh --check    # επαληθεύει ότι είναι συγχρονισμένα
```

## Έλεγχοι

```bash
node test/core.test.js      # 70 έλεγχοι — ΑΔΑΜ, ΑΦΜ, CPV, ποσά, ανάλυση, CSV
node test/worker.test.mjs   # 22 έλεγχοι — δρομολόγηση και ασφάλεια του Worker

python3 -m http.server 8765 &
node test/e2e.mjs           # 49 έλεγχοι — πλήρης ροή σε πραγματικό Chromium
```

Το `e2e.mjs` σηκώνει Chromium με προσομοιωμένο API ΚΗΜΔΗΣ και ελέγχει ολόκληρη
τη διαδρομή: σάρωση αλυσίδας από τον μεσαίο κρίκο, οικονομικά, τις τρεις
καρτέλες, τα κατεβάσματα αρχείων, το σκούρο θέμα και τη συμπεριφορά στα 360px.

## Τι διορθώθηκε από την v7

| Πρόβλημα | Αποτέλεσμα |
|---|---|
| `item.info.endpoint` δεν υπήρχε ποτέ στο `stageInfo` | **Όλα** τα PDF links και το ZIP παρήγαγαν `.../undefined/attachment/...` |
| `stageInfo.requests` (με `s`) — δεν υπάρχει τέτοιο κλειδί | Το fallback έσκαγε αντί να πιάσει |
| ΑΦΜ αναδόχου με regex σε όλο το JSON | Επέστρεφε ημερομηνίες και ποσά ως «ΑΦΜ» |
| `sw.js` ήταν JavaScript τυλιγμένο σε `<script>` | Δεν ήταν έγκυρος service worker· δεν καταχωριζόταν ποτέ |
| Η σελίδα χτυπούσε `/api/v1/...`, η επέκταση `POST /contract` | Δύο ασύμβατες υλοποιήσεις· η online δεν δούλευε |
| Δημόσιος proxy (allorigins) με rate limits | Αντικαταστάθηκε από δικό σου Cloudflare Worker |
| Σειριακά αιτήματα, χωρίς retry/timeout/cache | Αργό, και μια στιγμιαία αποτυχία χάλαγε όλη την αναζήτηση |
| Η αλυσίδα βρισκόταν μόνο με regex στο HTML | Έχανε στάδια· τώρα τέσσερις συνδυασμένες πηγές |

## Σημειώσεις

**Τα ονόματα πεδίων του API.** Το ΚΗΜΔΗΣ δεν δημοσιεύει σταθερό συμβόλαιο για το
opendata API. Ο κώδικας δέχεται πολλαπλές ονομασίες για κάθε πεδίο (π.χ. και
`totalCostWithoutVAT` και `estimatedTotalCostWithoutVAT` και `budget`) και
αγνοεί ήσυχα ό,τι λείπει. Αν κάποιο στοιχείο δεν εμφανίζεται, τα **🩺
Διαγνωστικά** δείχνουν τα πραγματικά ονόματα πεδίων που επέστρεψε ο server —
πρόσθεσέ τα στη λίστα `getBy([...])` του αντίστοιχου `extract*` στο
`khmdis-core.js`.

**Δεδομένα.** Όλα προέρχονται από τα δημόσια ανοικτά δεδομένα του Κ.Η.Μ.ΔΗ.Σ. και
της Διαύγειας και ανήκουν στους φορείς τους. Το εργαλείο δεν αποθηκεύει τίποτα σε
server — μόνο τις ρυθμίσεις σου, τοπικά στον browser.
